# Decisiones de arquitectura (ADR)

Cada archivo recoge una decisión que condiciona el trabajo futuro: por qué se
tomó, qué se descartó y qué consecuencias tiene. Para crear uno, desde la raíz
del repositorio: `nuevo-adr "Título de la decisión"`, a partir de
[la plantilla](0000-plantilla.md).

El registro empezó el 23 de septiembre de 2026. Los ADR 1 a 7 se redactaron
entonces a partir del código y del historial, con la fecha en que se tomó cada
decisión; describen el proyecto tal como está, y sus alternativas son las
evidentes para cada caso, no un registro de lo que se valoró entonces. Los cambios, versión a versión,
están en [CHANGES.md](../../CHANGES.md).
